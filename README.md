# Virtualization Lab (Hyper-V & VMware ESXi)

## Purpose
This project demonstrates hands-on experience with virtualization technologies using both Hyper-V and VMware ESXi.

---

## Technologies
- Hyper-V
- VMware ESXi 8
- VMware Workstation (Nested virtualization)
- Windows Server
- Ubuntu Server

---

## What I built

### Hyper-V Environment
- Installed and configured Hyper-V
- Created virtual machines (Generation 2)
- Configured networking (External Switch)
- Managed storage (VHDX)
- Implemented checkpoints

### VMware ESXi Lab (Nested)
- Installed ESXi inside VMware Workstation
- Configured networking (NAT)
- Created datastore and VM
- Installed Ubuntu Server
- Implemented snapshots and recovery testing

---

## Key Skills Demonstrated
- Virtual machine provisioning
- Network configuration
- Storage management
- Snapshot / checkpoint handling
- Troubleshooting virtualization issues
