# Hyper-V Lab

## Overview
This lab focuses on setting up and managing virtual machines using Hyper-V.

---

## What I did

- Enabled Hyper-V feature in Windows
- Created Generation 2 virtual machines
- Configured external virtual switch
- Managed virtual hard disks (VHDX)
- Created checkpoints

---

## Configuration

### Virtual Machines
- OS: Windows / Linux
- Generation: Gen 2
- Storage: VHDX

### Networking
- External Virtual Switch
- Connected VMs to network

---

## Result
- Virtual machines successfully created and running
- Network connectivity working
- Checkpoints used for recovery testing
