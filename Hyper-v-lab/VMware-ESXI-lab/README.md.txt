# VMware ESXi Lab (Nested Virtualization)

## Overview
This lab demonstrates installation and configuration of VMware ESXi in a nested environment.

---

## What I did

- Installed VMware Workstation
- Created nested ESXi environment
- Installed VMware ESXi 8
- Configured networking (NAT)
- Created datastore
- Deployed virtual machine (Ubuntu Server)

---

## Configuration

### ESXi Host
- Installed ESXi 8
- Accessed via Web Client

### Storage
- Created datastore
- Managed VM storage

### Virtual Machines
- Ubuntu Server installed
- Snapshot functionality tested

---

## Result
- ESXi host running successfully
- Virtual machines deployed and accessible
- Snapshots working for rollback scenarios
